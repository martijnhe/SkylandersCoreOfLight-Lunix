Skylanders: Core of Light for Linux and the Steam Deck

Install
  Unpack this ZIP into a folder of its own, for example ~/Applications/CoreOfLight, and start
  coreoflight. It needs no installation and updates itself from new releases.

Steam Deck
  1. In Desktop Mode, unpack the ZIP into a folder (on the internal drive or the microSD card).
  2. In Steam: Games > Add a Non-Steam Game to My Library > Browse, and pick coreoflight.
  3. Back in Gaming Mode, start it from the library. It opens in fullscreen and works with the
     Deck's controls; no launch options are needed.
  The launcher sets up the Linux builds of the games. In its settings, Games folder can put them on
  the microSD card.

Where things are
  Saves, figures and settings: ~/Documents/Skylanders (the same folder the games use)
  Games installed by the launcher: ~/.local/share/CoreOfLight/Games
  The launcher's log: ~/.local/share/CoreOfLight/coreoflight.log
